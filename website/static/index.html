💡 How it works

          

            The ECU writes pixel data into OLED_Buffer[1024] in
            page format — each byte represents 8 vertical pixels.
            The buffer is pushed to the display via I2C every frame.


            This simulation fetches the same frame data that was compiled into the ECU
            and replays the animation in your browser at the same speed.


            ⚠ Simulation mode — not a live mirror.
            To mirror the real display, the ECU would need to stream
            $OLED:<1024 bytes> over UART.
